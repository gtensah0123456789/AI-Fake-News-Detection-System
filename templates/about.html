About the AI-Based Fake News Detection System

An end-to-end full-stack Machine Learning web application designed to assist readers in screening news headlines and articles for linguistic indicators of misinformation.

1. What is Fake News?

Fake news refers to fabricated, sensationalized, or deliberately misleading stories presented as legitimate journalism. It often relies on emotional triggers, unverified claims, clickbait phrasing, and false urgency to spread rapidly across digital platforms.

2. Why Detection Matters

Automated preliminary screening helps users pause and evaluate suspicious claims before sharing them, reducing the spread of health hoaxes, financial scams, and public panic while promoting digital media literacy.

3. Machine Learning Workflow

Step 1: Preprocessing

Lowercasing text, removing URLs, HTML tags, punctuation, numbers, and extra whitespace.

Step 2: TF-IDF

Converts words and 2-word phrases (bigrams) into weighted numerical feature vectors.

Step 3: Classification

Logistic Regression computes class probabilities for REAL vs. FAKE.

Step 4: Persistence

Predictions and confidence scores are logged into SQLite for dashboard visualization.

4. Technology Stack

Layer Technologies Used Role in System
Frontend HTML5, CSS3, JavaScript (ES6), Bootstrap 5, Chart.js Responsive UI, async API calls, interactive charts & validation
Backend Python 3, Flask REST API Serves templates, validates requests, runs inference & DB queries
Machine Learning Scikit-learn, Pandas, NumPy, Joblib TF-IDF vectorization, Logistic Regression training & serialization
Database SQLite3 Lightweight persistent storage for prediction history & stats
Academic Integrity Note: Machine Learning classifiers identify statistical patterns from labeled training datasets. They cannot verify real-time breaking events or guarantee 100% factual accuracy.
