# AI-Based Fake News Detection System

A full-stack Machine Learning web application built with **Python, Flask, Scikit-learn (TF-IDF + Logistic Regression), SQLite, and Bootstrap 5**. Users can paste news headlines or articles to classify them as **Likely Real** or **Likely Fake**, inspect confidence percentages, and monitor prediction statistics on a live analytics dashboard.

> **Disclaimer:** Predictions are statistical probability estimates generated by a Machine Learning model trained on text patterns—not guaranteed factual verification.

---

## Features

- **Real-Time News Analysis:** Paste any news headline or full article and receive instant ML classification (`Likely Real` or `Likely Fake`), confidence score, and key influential terms.
- **Trained NLP Pipeline:** Uses text normalization, TF-IDF vectorization (unigrams + bigrams), and balanced Logistic Regression serialized via `joblib`.
- **SQLite Persistence:** Automatically stores every analyzed article, prediction label, confidence score, and timestamp in `database/predictions.db`.
- **Interactive Analytics Dashboard:** Displays KPI cards, Doughnut and Bar charts (via Chart.js), recent prediction history, and a one-click history reset button.
- **Beginner-Friendly & Demo-Ready:** Includes one-click sample Real/Fake buttons for smooth live classroom demonstrations.

---

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5, Bootstrap Icons, Chart.js
- **Backend:** Python 3, Flask REST API
- **Machine Learning:** Pandas, NumPy, Scikit-learn (`TfidfVectorizer`, `LogisticRegression`), Joblib
- **Database:** SQLite3

## Dataset Attribution & Updating Instructions

- **Included Dataset (`data/news_dataset.csv`):** Contains 120 balanced, curated educational benchmark examples (`60 REAL`, `60 FAKE`) modeled after standard fake-news NLP classification benchmarks (such as the **ISOT Fake News Dataset** by Ahmed et al., University of Victoria, and the **WELFake Dataset**, IEEE Transactions on Computational Social Systems). It is intentionally structured so `train_model.py` runs out-of-the-box in seconds during local setup and college demonstrations.
- **How to Upgrade to a Full-Scale Dataset:**
  1. Download a full public dataset such as the [WELFake Dataset on Kaggle](https://www.kaggle.com/datasets/saurabhshahane/fake-news-classification) or [ISOT Fake News Dataset](https://onlineacademiccommunity.uvic.ca/isot/2022/11/27/fake-news-detection-datasets/).
  2. Format the CSV with two columns: `text` (article body/headline) and `label` (`REAL` or `FAKE`).
  3. Replace `data/news_dataset.csv` and re-run `python train_model.py` to regenerate `model/trained_model.pkl`.

## macOS Setup & Running in VS Code

1. **Open the Project in VS Code:**
   Open VS Code, click **File > Open Folder...**, and select `Fake_News_Detection_System`.
2. **Open Integrated Terminal (`Ctrl + ~` or `Cmd + J`) and create a virtual environment:**
   ```bash
   python3 -m venv venv
   ```
3. **Activate the virtual environment:**
   ```bash
   source venv/bin/activate
   ```
4. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
5. **Train the Machine Learning model:**
   ```bash
   python train_model.py
   ```
6. **Run the Flask web application:**
   ```bash
   python app.py
   ```
7. **Open in Browser:**
   Visit `http://127.0.0.1:5000` in Safari, Chrome, or Firefox.
